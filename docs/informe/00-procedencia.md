# Procedencia, autoría y uso de IA

## Código base reutilizado

Gym Track se reutiliza de un proyecto de otra materia. El archivo de referencia es `gym-track-app-completa.zip`, cuya carpeta raíz contiene `g-t-api`, `g-t-portal`, `g-t-db` y `g-t-infra`. La aplicación procede de varios repositorios; las URL y revisiones originales exactas están por verificar.

La importación, sus pruebas preexistentes y su documentación no se presentan como desarrollo nuevo de Métricas y Estándares de Calidad. El historial existente se conserva: no se recrean commits, no se cambian fechas y no se reparten importaciones para simular desarrollo.

## Trabajo de esta materia

El alcance comprende validar las pruebas, completar escenarios por área, preparar y ejecutar mediciones reproducibles, interpretar resultados, registrar mantenimiento, realizar mejoras verificadas y elaborar documentación e informe. Una actividad solo se declara terminada cuando existen sus archivos, commits y evidencias reales.

## Inteligencia artificial

Se utilizó IA para revisar los adjuntos y preparar esta declaración y las instrucciones de colaboración. El historial adjunto atribuye generación asistida por IA al código base; el equipo debe verificar y completar esa declaración con las herramientas y tareas que realmente utilizó.

Las futuras asistencias de IA se registrarán indicando tarea y archivos afectados. Cada integrante revisa, ejecuta y debe poder explicar el código que entrega. La IA no acredita pruebas ejecutadas, mediciones ni autoría individual.
